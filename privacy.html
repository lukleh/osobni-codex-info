Privacy policy

Effective date: 18 November 2026

Purpose and data access

Osobní Codex is a personal integration used only by its owner, Lukas Lehner. Depending on the task requested by the owner and the permissions granted, it can access and modify Google Drive files, Google documents, Gmail messages and labels, Calendar events, and Google Cloud API configuration. Basic Google account information identifies the authorized account.

Use and processing

Google data is used only to carry out the owner's requested productivity and automation tasks. Relevant data may be processed by the tools and service providers the owner chooses to use for those tasks, under those providers' applicable terms and privacy policies. The integration does not sell Google user data or use it for advertising. Google user data is not used by this integration to develop or train generalized machine learning models.

Storage and security

OAuth credentials are stored separately from this public website. The CLI stores saved credentials encrypted on the owner's computers, using the operating system keychain where available. Task outputs or working copies may be retained in locations selected by the owner. This website and its public repository contain no Google account data or OAuth credentials.

Retention and control

The owner controls retention and deletion of local credentials and task outputs and can revoke this integration's access in Google Account settings at any time. Revoking access stops future API access; retained copies and tool history can be deleted separately through the tools that hold them. Changes to source data are made only as requested by the owner.

Google API user data

Use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Website hosting and contact

These static information pages are hosted by GitHub Pages. GitHub may process standard web request information under its own privacy statement. The pages add no analytics, cookies or tracking scripts.
