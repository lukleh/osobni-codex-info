Osobní Codex

A private, single-user command-line integration maintained by Lukas Lehner for personal use. It connects the owner's Google account to tools used for personal productivity and automation.

The integration uses Google Workspace CLI (gws) and Google APIs to work with the owner's Google Drive files, Google documents, Gmail and Calendar, and to manage API availability in the owner's Google Cloud project.

It is not offered as a public service and does not provide registration or access for other users. Access to Google data requires the owner's explicit OAuth consent.
